ExamDesk 离线考试系统 1.0.0
===========================

一、发行版本

1. 主管理员版用于题库、考试场次、答题记录、协作管理员和系统维护。
2. 考生协作版用于正式考试、练习和离线协作题库。
3. 两个版本均适用于 Windows 10 x64，不需要目标电脑另外安装 Python。
4. 软件完全离线运行，不依赖服务器、互联网或共享目录。

二、首次初始化

1. 主管理员版首次进入管理员入口时，可以创建主管理员，也可以从加密备份恢复。
2. 创建主管理员时必须保存一次性显示的系统恢复码。
3. 初始化后进入“系统维护”，导出 .examtrust 信任证书。
4. 考生电脑可以安装多个不同管理员发放的信任证书。

三、题库维护

1. 支持单选题、多选题、判断题和多空填空题。
2. 支持逐题编辑，以及 Excel、Word、文本题库批量导入。
3. Excel 标准表头为：编号、章节、题型、题目、A、B、C、D、答案、依据、分值、题图、A图、B图、C图、D图、状态、使用范围、适用年份、来源、条款、难度、标签。
4. 题目或选项只有图片而没有文字时，只要有效选项不少于两个，也可以导入。
5. 同一单元格可放置多张嵌入图片，按图片左上角位置从左到右、从上到下排序。
6. 图片也可以填写相对于 Excel 文件位置的路径，多张路径使用英文分号分隔。
7. 填空题多个空使用英文分号分隔，同一空的同义答案使用 / 分隔。
8. 无序填空示例：@1-3,5-7|答案1;答案2;答案3;答案4;答案5;答案6;答案7;答案8
9. 填空分值只填写一个数字时，每个空使用相同分值。
10. “依据”可以留空。
11. 题库支持筛选、表头排序、批量启用、停用、修改和删除。
12. 导出 Excel 会保持标准表头并嵌入题图和选项图，导出的文件可以再次导入。

四、创建考试

1. 进入“考试场次”，创建场次并设置题量、筛选条件、名单、考试密码、次数、限时和答案查看策略。
2. 考试密码为可选项。无密码考试包不提供答案保密性。
3. 切屏监控默认关闭。需要时由管理员主动勾选“启用切屏监控”。
4. 启用监控后，考生开考前会看到采集范围并决定是否继续。
5. 场次锁定后导出 .exampack 文件。锁定场次不能修改，需要调整时重新创建。

五、正式考试

1. 考生选择 .exampack，首次使用时安装管理员提供的 .examtrust。
2. 输入姓名；设置了考试密码的场次还需输入本场密码。
3. 启用监控的场次会在创建答题状态前显示独立告知。不同意将直接返回。
4. 监控可能记录软件名称、进程名称、窗口标题、切出时间和持续时长。
5. 答题时可以使用上一题、下一题、答题卡和标记功能。
6. 限时考试到时自动交卷。
7. 交卷后生成 .examresult 文件，并在本机保存加密结果副本。

六、练习

1. 管理员从题库导出 .practicepack，可设置或不设置练习包密码。
2. 使用者自行选择各题型数量。
3. 点击“核对本题”后答案锁定，并立即显示得分、正确答案和依据。
4. 练习结束后可以复盘错题、题图和选项图。
5. 练习模式不启用切屏监控。

七、收卷与报表

1. 管理员在“答题记录”中批量导入 .examresult。
2. 重复文件不会重复导入，多次作答和异常记录会保留。
3. 相似填空答案可以由管理员复核。
4. 支持导出整场 Excel 汇总和个人 PDF 答卷。
5. 启用监控的场次会在报表中显示切屏次数、持续时间、软件和窗口标题。

八、加密备份与恢复

1. “系统维护－创建加密备份”会备份数据库、题库图片、管理员、场次、答题记录、组织签名和收卷密钥。
2. 备份密码至少8个字符。备份文件、密码和 .examtrust 信任证书应分开保存。
3. 已有主管理员可以在“系统维护－恢复加密备份”中恢复。
4. 新电脑首次进入管理员入口时，点击“从加密备份恢复”。
5. 新电脑恢复必须同时选择原管理员导出的 .examtrust 信任证书。
6. 恢复时输入备份密码和大写 RESTORE。已有数据的电脑还要再次输入当前主管理员密码。
7. 已有数据恢复前会自动创建一份当前状态安全备份。
8. 备份通过签名、密码和完整性校验后，先在临时目录展开；全部成功才替换数据库和图片。
9. 组织私钥会重新使用目标电脑当前 Windows 用户保护。恢复完成后软件退出，重新打开生效。
10. 密码、备份文件或信任证书丢失时，无法保证完成跨电脑恢复。

九、系统维护

1. 主管理员可以添加或移除副管理员、重新生成恢复码、查看操作审计和恢复出厂状态。
2. 新恢复码生成后旧恢复码立即失效，新码只显示一次。
3. 恢复出厂状态会清空本机全部应用数据，应先创建并验证加密备份。

十、隐私与安全边界

1. 程序数据默认保存在 %LOCALAPPDATA%\ExamDesk。
2. 切屏监控只在管理员主动启用且考生确认后运行。
3. 离线即时判分要求答案材料到达考生电脑，软件不能单独阻止主动修改客户端或分析本地运行数据。
4. 正式考试应结合现场监督、受控电脑和组织管理措施。

十一、重要文件

.exampack      正式考试包
.practicepack  练习包
.examresult    加密答题记录
.examtrust     考试信任证书
.exambackup    加密完整备份
.bankwork      协作题库工作包
.bankpatch     题库变更包

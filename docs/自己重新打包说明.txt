ExamDesk 1.0.0 自己重新打包说明
================================

一、准备环境

1. 使用 Windows 10 x64，并安装 Python 3.11 x64。
2. 直接双击“一键重新打包.cmd”即可。脚本会按以下顺序寻找构建环境：

   手动传入的 -PythonPath
   环境变量 EXAMDESK_BUILD_PYTHON
   项目根目录的 .venv311
   项目根目录的 .venv

3. 如果没有找到完整环境，脚本会自动寻找本机 Python 3.11 x64，创建项目专用的 .venv311，并安装 .[dev] 中的全部依赖。
4. 首次自动安装依赖通常需要互联网。成功准备后，只要保留 .venv311，以后在同一台电脑上重新打包不需要再次下载。
5. 离线电脑已有其他完整构建环境时，可以把 EXAMDESK_BUILD_PYTHON 设置为该环境的 python.exe。脚本会检查 Python 版本、64 位架构和所有打包依赖，不合格时会停止并说明原因。
6. 首次安装依赖默认使用清华大学 PyPI 镜像。如果该镜像无法访问，可以设置环境变量 EXAMDESK_PIP_INDEX_URL，或运行 packaging\rebuild_release.ps1 时传入 -PipIndexUrl 指定其他镜像，例如 https://pypi.org/simple。
7. 如果项目或虚拟环境路径含中文，一键脚本会在同一磁盘创建临时的纯英文硬链接依赖镜像供 Nuitka 使用，构建结束后自动删除，不会复制完整虚拟环境，也不需要手动移动项目。

二、执行打包

双击项目根目录的“一键重新打包.cmd”。脚本会依次：

1. 生成 ExamDesk 图标；
2. 运行全部自动测试；
3. 运行 Ruff；
4. 构建主管理员版；
5. 构建考生协作版；
6. 生成 Python 源码包；
7. 生成 SHA-256 校验值。

三、输出文件

结果位于项目根目录的 release 文件夹：

ExamDesk_1.0.0_主管理员版_Windows10_x64.zip
ExamDesk_1.0.0_考生协作版_Windows10_x64.zip
ExamDesk_1.0.0_Python源码.zip
SHA-256校验值.txt

四、注意事项

1. 打包脚本会清理项目专用的临时构建目录，不会删除题库或本机应用数据。
2. 发布前检查 release 中没有数据库、证书、考试包、答题记录或真实题库。
3. 发布二进制包时保留 LICENSE、THIRD_PARTY_NOTICES.md、PRIVACY.md 和 licenses 目录。
4. 不要移动或删除 .venv311；它是后续离线重新打包所需的项目构建环境。
5. 如果更换电脑，虚拟环境不建议直接复制。请在联网电脑上重新运行一次一键脚本，或使用该电脑上已经准备好的 Python 3.11 x64 构建环境。
